## Реализация

### Конфигурация слейвов Postgres

[docker-compose](./docker-compose.yaml#L118)

по примеру ранее выполненного задания на репликацию (задание №3) реализовал 1 мастер ноду и 2 реплики.

### Конфигурация HAProxy

Затем сконфигурировал ([сервис](./docker-compose.yaml#L106) | [конфиг](./haproxy.cfg)) haproxy таким образом чтобы приложение при использовании реплик через haproxy ноду подключалось к одной из реплик (для простоты по стратегии round-robin). клиенты подключаются к фронтовой части haproxy к порту 5001 заданному в конфиге, а далее сервис балансирует трафик между 2мя нодами постгреса описанными в конфиге. Помимо этого 1 раз в 3 сек происходит проверка доступности каждой из нод.

### Конфигурация nginx

[nginx.conf](./nginx.conf)

Сконфигурировал nginx таким образом, чтобы клиент при запросе на порт 8282 перенаправлялся на нгинкс на порт 80, а затем на одну из реплик sm-gateway сервиса. Внутренний Docker DNS видит N запущенных контейнеров sm-gateway и по round-robin балансирует нагрузку между ними. В дальнейшем нужно будет воспроизвести нагрузку и возможно какие-то настройки еще подтюнить.
